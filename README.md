**pokemon-hau-flutter-app**
A stunning, high-performance Flutter mobile application that brings the world of Pokemon to life with modern aesthetics, smooth animations, and real-time PokeAPI data integration.

### 01 — INSTALL

Bash
> git clone https://github.com/ciellamher/pokemon-hau-flutter-app.git
> cd pokemon-hau-flutter-app
> flutter pub get

---

### 02 — USE

> flutter run

Launch the app on a connected iOS/Android device or emulator to explore the Pokedex.

---

### 03 — WHAT'S INSIDE

- `lib/main.dart` — The application root and theme configuration.
- `lib/screens/` — UI views including the main list and detailed stats pages.
- `lib/api/` — Network handlers fetching real-time data from the PokeAPI.
